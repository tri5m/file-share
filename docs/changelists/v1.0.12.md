# FileShare v1.0.12

## Windows 体验与稳定性

- 再次启动 FileShare 时唤醒已有窗口，恢复隐藏或最小化状态，不创建第二个托盘或服务实例。
- 多实例唤醒不会停止或重启当前分享，正在进行的上传、下载和实时同步保持不变。
- 中文 Windows 根据系统语言显示中文端口占用和启动失败提示，英文系统保持英文提示。

## 网卡选择改进

- 多网卡时优先选择真实的以太网、Wi‑Fi、WLAN、AirPort、Thunderbolt Bridge 和 USB LAN 网卡。
- 过滤 vEthernet、Hyper‑V、WSL、Docker、VirtualBox、VMware、VPN、WireGuard、桥接、Host‑Only、NAT 等虚拟或隧道网卡，减少不可访问地址被选中的情况。
- macOS 和 Windows 均按网卡优先级排序，生成更可靠的分享地址。
