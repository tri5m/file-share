# FileShare v1.0.11

本次更新包含自 v1.0.10 以来的功能更新、体验优化和稳定性修复。

## 新增与优化

- 网页左上角及浏览器标签页显示分享来源电脑的主机名，方便同时打开多个分享页面时区分设备。
- 上传文件弹窗内新增任务列表，逐个展示文件名、进度、速率，以及等待上传、上传中、正在保存、已完成或失败状态。
- 支持上传排队、取消和失败重试；关闭上传弹窗后任务继续进行，再次打开可查看进度。
- 管理端停止分享时，已连接的网页会显示“分享已停止”，停止继续上传和自动重连；分享重新开启后可点击“刷新页面”恢复使用。普通网络中断仍会自动重连。
- 共享列表中的文本和文件标记使用不同颜色，内容类型更容易辨认。
- 网页端“上传文本”统一调整为“共享文本”，“QQ群”调整为“交流群”。

## 问题修复

- 修复管理端部分访问来源下出现 `TypeError: Load failed`、无法加载共享列表或实时同步的问题。
- 修复使用说明浮层在小窗口中超出边界的问题，改为居中弹窗，内容过高时可在弹窗内滚动阅读。
- 文本提交失败时显示错误并保留输入内容，避免重复输入；提交期间防止重复发送。
- 提升托盘和窗口同时操作时的分享启停稳定性，修复切换端口后实时连接可能未更新的问题。
- 提升分享重启期间的列表保存和实时同步可靠性，避免正在收尾的上传遗漏到新连接的共享列表之外。
- 提升同名文件并发上传、上传失败清理和共享列表保存的可靠性，增加元数据备份恢复，避免覆盖已有文件。
- 修复部分下载请求结束后，管理端仍残留“正在下载”状态的问题。

## 更新说明

- 提供 macOS Apple Silicon、macOS Intel 和 Windows x64 版本。
- 已安装用户可通过系统托盘中的“检查更新”升级；网页客户端刷新后即可使用新版页面。
