# FileShare v1.0.12-rc.1

这是 v1.0.12 的候选版本，重点验证 Windows 多实例唤醒、网卡选择和系统语言提示。

## Windows 修复

- 再次启动 FileShare 时唤醒已有窗口，恢复隐藏或最小化状态，不创建第二个托盘或服务实例。
- 多实例唤醒不会停止或重启当前分享，正在进行的上传、下载和实时同步保持不变。
- 增加 Windows 进程间唤醒通知，并覆盖重复启动和启动期间通知暂存测试。
- 中文 Windows 根据系统用户区域显示中文端口占用和启动失败提示，英文 Windows 保持英文提示。

## 网卡选择改进

- 真实以太网、Wi‑Fi、WLAN、AirPort、Thunderbolt Bridge 和 USB LAN 网卡优先识别。
- 排除 vEthernet、Hyper‑V、WSL、Docker、VirtualBox、VMware、VPN、WireGuard、桥接、Host‑Only、NAT 等虚拟或隧道网卡。
- 多网卡时按优先级排序，避免虚拟网卡成为默认分享地址。

这是候选版本，建议重点验证 Windows 上的重复启动、托盘隐藏后再次启动，以及多网卡环境下客户端链接是否可访问。
